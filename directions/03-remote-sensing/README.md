# 遥感图像识别

面向卫星、航空与无人机遥感影像的自动解译，核心难点是尺度差异极大、目标密集、方向任意，以及标注成本高导致的监督信号稀缺。

## 研究范围

- 遥感场景分类与地物识别
- 遥感目标检测（旋转框、密集小目标）
- 遥感语义分割与变化检测
- 遥感图像-文本跨模态理解与检索
- 自监督 / 半监督在遥感中的应用

**关键词**：remote sensing, aerial imagery, oriented object detection, change detection, semantic segmentation, scene classification, remote sensing vision-language

## 建议阅读顺序

1. 先按任务看综述：场景分类 → 目标检测 → 语义分割 → 变化检测，这四个子任务的方法演进基本独立。
2. 再关注跨模态这条新线（遥感图文预训练），这是近两年增长最快的部分。
3. 数据集比方法更容易踩坑——务必先看清楚标注形式（水平框 / 旋转框 / 多边形）和分辨率。
