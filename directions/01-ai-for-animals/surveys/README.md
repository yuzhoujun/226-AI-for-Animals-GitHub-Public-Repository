# 综述

新建年份文件时，直接复制 [`templates/surveys-year.md`](../../../templates/surveys-year.md)。

**新加入这个方向的同学，从这里开始读。** 最近两年的综述能最快建立整体认识。

判定标准：系统梳理已有进展、而非提出新方法的论文（Survey / Review / Tutorial）都放这里。
