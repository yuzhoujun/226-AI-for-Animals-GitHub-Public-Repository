# 图像拼接

把多张存在重叠区域的图像对齐并融合成一张无缝的大视场图像，是全景成像、航拍测绘、医学影像拼接等应用的基础技术。

## 研究范围

- 特征检测、描述与匹配
- 图像配准与单应性估计
- 全景拼接、柱面/球面投影
- 图像融合与接缝处理（去鬼影、曝光补偿）
- 视频拼接与实时拼接

**关键词**：image stitching, image registration, feature matching, homography estimation, seam carving, image blending, panorama

## 建议阅读顺序

1. 传统方法这条线不能跳过：SIFT → RANSAC → 单应性估计，是理解后续所有深度学习方法的基础。
2. 再看深度学习路线：从监督学习单应性，到无监督/自监督的拼接框架。
3. 重点关注**大视差**和**低重叠**这两个老问题，新工作基本都在这两点上做文章。

## 和动物方向的关系

本身不面向动物，但无人机航拍影像拼接是野生动物监测（尤其是大范围种群调查）的常见前置环节。
