# 多模态目标识别

融合视觉与语言（以及音频、深度等）多种模态进行目标检测与识别，重点是让模型能按自然语言描述定位和区分目标，而不局限于固定的类别表。

## 研究范围

- 视觉-语言预训练与跨模态对齐
- 开放词汇 / 零样本目标检测
- 多模态目标识别与指代理解（Referring Expression Comprehension）
- 图文检索与跨模态表征学习
- 多模态大模型在检测识别任务上的适配

**关键词**：vision-language pretraining, open-vocabulary detection, cross-modal alignment, CLIP, referring expression, multimodal fusion
