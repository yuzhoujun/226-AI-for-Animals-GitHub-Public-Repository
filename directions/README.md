## 关于编号

编号决定目录在文件列表里的排序，也决定了新方向往哪加。**新方向一律取下一个可用编号**（当前是 `05`），不要插空号或重排已有编号——重排会让所有人的本地分支和已有链接全部失效。

## 新增方向

先开 [Issue](../.github/ISSUE_TEMPLATE/new-direction.yml) 讨论，确认后再建目录。步骤见 [CONTRIBUTING.md](../CONTRIBUTING.md#新增一个研究方向)。

## 方向之间的交叉

有些论文会同时属于两个方向。**只在最主要的方向里收录一份，不要重复放**，避免同一条内容出现两个版本、日后更新时只改了一处。如果确实交叉明显，在该方向 README 里提一句「与 XX 方向高度相关」即可。
